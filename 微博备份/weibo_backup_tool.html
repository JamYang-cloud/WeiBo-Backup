📖 完整使用指南

🔧 什么是 UID？

每个微博用户有一个唯一的数字 ID（UID）。打开用户主页，URL 中的数字就是 UID：
https://weibo.com/u/1041241542

📋 如何使用 Console 执行 JS 代码？

  1. 在 Chrome 浏览器 中登录微博（weibo.com）
  2. 打开目标用户的个人主页：https://weibo.com/u/{UID}
  3. 按键盘 F12 打开开发者工具
  4. 点击顶部 Console（控制台） 标签
  5. 复制上方生成的代码，粘贴到 Console 中
  6. 如果粘贴被阻止，先输入 allow pasting 后按 Enter
  7. 按 Enter 键执行
  8. 等待脚本运行完成，会自动下载一个 JSON 文件

⚠️ 环境要求

操作系统 Windows / macOS / Linux（只要有 Chrome 浏览器即可）
浏览器 Chrome（推荐）、Edge、Firefox 均可
其他软件 完全不需要！本工具就是一个 HTML 文件，双击打开即可
网络 需要互联网（访问微博和加载 JSZip 库）

🚫 已知局限性

  • 图片无法自动提取 — 微博 API 在列表接口中不返回图片数据，且 DOM 提取方式不可靠。您需要手动保存图片
  • 无法在手机上运行 — 需要在桌面版 Chrome 中执行
  • 需保持登录状态 — 提取前需确保微博已登录
  • 可能触发风控 — 抓取过多过快可能导致暂时封禁，建议保持 3 秒以上间隔
  • 长文本自动展开 — 脚本会自动调用展开长文本的 API，但极少数情况下可能失败
  • 仅备份文字内容 — 视频、投票、定位等富媒体内容暂不支持
  • 浏览器 JSZip 依赖 — ZIP 导出功能需要联网加载 JSZip 库

📂 输出格式说明

每个 Markdown 文件格式： --- type: 微博 date: 2026.05.28 tags: [] description: "" --- 微博正文内容... - 2026.05.28

🔄 增量备份说明

本工具使用浏览器 localStorage 记录上次备份时间。当启用"增量备份"时，生成的 Console 代码会 自动跳过上次备份时间之前的微博，只提取新内容。清除浏览器数据会丢失记录。
