# 📱 Weibo Archiver — 微博备份工具

一个图形化的微博备份工具，**无需安装任何软件**，只需一个 HTML 文件和 Chrome 浏览器即可完成微博内容的抓取与归档。

## 🎯 主要功能

| 功能 | 说明 |
|------|------|
| **一键生成 JS 代码** | 设置参数后自动生成可执行的 Console 代码 |
| **智能文本抓取** | 自动展开长文本，获取完整微博内容 |
| **时间范围过滤** | 可按日期范围或增量备份方式提取 |
| **增量备份** | 记录上次备份时间，下次自动跳过已备份内容 |
| **JSON → Markdown** | 将抓取结果转换为单篇 Markdown 文件 |
| **批量导出 ZIP** | 一键下载所有 Markdown 文件 |

## 🚀 快速开始

### 第一步：打开工具

双击 `weibo_backup_tool.html`，在浏览器中打开。

### 第二步：配置参数

1. 输入目标用户的 **UID**（用户主页 URL 中的数字）
2. 设置抓取 **页数**（每页约 15-20 条）
3. 可选：设置 **日期范围** 或启用 **增量备份**

### 第三步：复制代码到 Chrome

1. 点击「复制」按钮，复制生成的 JS 代码
2. 在 Chrome 中登录微博，打开用户主页
3. 按 **F12** → Console → 粘贴 → **Enter**

### 第四步：等待抓取完成

脚本会自动滚动加载所有微博，完成后自动下载一个 JSON 文件（存储在下载文件夹中）。

### 第五步：转换为 Markdown

1. 回到工具页面，切换到 **JSON 转 Markdown** 标签
2. 上传刚才下载的 JSON 文件
3. 点击「生成并下载 ZIP」

## 📋 详细使用说明

### 什么是 UID？

每个微博用户有一个唯一的数字 ID。在浏览器中打开用户主页：
```
https://weibo.com/u/1041241542
```
其中的 `1041241542` 就是 UID。

### 如何使用 Console 执行 JS 代码？

1. 在 **Chrome 浏览器** 中登录微博（weibo.com）
2. 打开目标用户的个人主页：`https://weibo.com/u/{UID}`
3. 按键盘 **F12** 打开开发者工具
4. 点击顶部 **Console（控制台）** 标签
5. 如果在 Console 中粘贴被阻止，输入 `allow pasting` 后按 **Enter** 即可解除限制，然后再粘贴
6. 按 **Enter** 键执行
7. 等待脚本运行完成（控制台会打印进度），会自动下载一个 JSON 文件

### 增量备份怎么用？

该功能使用浏览器的 `localStorage` 记录上次备份时间。

1. 首次备份：直接设置参数后执行，完成后点击「设为当前时间」
2. 下次备份：工具会自动读取上次备份时间，生成的代码只提取新内容

> ⚠️ 清除浏览器数据会丢失备份时间记录

## 🚫 已知局限性

- **⚠️ 图片无法自动提取** — 微博 API 在列表接口中不返回图片数据，且从页面 DOM 提取图片的方式因反爬机制而不可靠。如需配图，请手动保存
- **需要在桌面浏览器中运行** — 手机浏览器不支持 Console 功能
- **需保持微博登录状态** — 提取前需确保已在浏览器中登录微博
- **可能触发风控** — 抓取过快（间隔 < 2 秒）可能导致临时封禁。建议保持 3 秒以上间隔
- **仅备份文字内容** — 视频、投票、定位等富媒体内容不包含在备份中
- **极少数长文本可能展开失败** — 如遇此情况可重试

## 📂 输出格式

生成的每个 Markdown 文件格式如下：

```markdown
---
type: 微博
date: 2026.05.28
tags: []
description: ""
---

微博正文内容... - 2026.05.28
```

- `tags` 和 `description` 保留为空，可用其他工具（如 DeepSeek API）补充
- 文件名格式：`微博-YYYY.MM.DD-序号.md`（序号自动递增，5 位补零）

## 🔧 工作原理

1. 工具生成一段 **JavaScript 代码**，您将其粘贴到浏览器 Console 中执行
2. 这段代码直接调用微博的 **内部 API** `ajax/statuses/mymblog` 获取微博数据
3. 对于长文本，自动调用 `ajax/statuses/longtext` 展开全文
4. 抓取完成后，将数据导出为 **JSON 文件**（通过浏览器自动下载）
5. 工具读取 JSON，将其拆分为单篇 **Markdown 文件**，打包为 ZIP 下载
